# 独立 GPT Image 2 生图站任务清单

## 使用规则

- 按编号顺序执行，未通过当前任务不得进入下一项。
- 每项任务都必须同时满足“完成标准”“必做测试”“失败回退检查”。
- 任一测试失败时，停止推进，修复当前任务，再重新执行该任务测试。
- 不允许跳过安全、存储、错误处理、响应式和部署验证任务。
- 不允许新增用户系统、服务端数据库、服务端图片存储、对象存储或后端代理。
- 不允许把 API Key 发送到配置的 Sub2API 后端以外的任何服务。
- 不允许把大图保存到 localStorage。
- 所有图片请求必须固定使用 `gpt-image-2`。
